# Project Instructions

- Keep `layouts/layouts.md` synchronized with the active keymap in `config/totem.keymap`. Any change to mappings, layers, layer access, shortcuts, or tap-hold timing must update `layouts/layouts.md` in the same change.
- After changing `layouts/layouts.md` or `layouts/print.css`, run `./layouts/generate.sh`, visually review the generated HTML opened in the browser, and commit `layouts/layouts.html` in the same change.
